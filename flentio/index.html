⚙️ Arquitectura de Flujo

¿Cómo Funciona un Flujo de Trabajo en Flentio?

A diferencia de un buscador manual, Flentio procesa la información en forma de cadena de ejecución visual desde una entrada hasta una acción final.

Estructura del Flujo

1. Nodo de Entrada (Trigger): Se activa al recibir una petición (ej. llega una consulta o factura por correo).

2. Nodo de Seguridad (DLP): Oculta automáticamente NIF, IBAN o tarjetas de la petición.

3. Nodo Agente de IA: Evalúa la solicitud consultando documentos de referencia con citas obligatorias [E1].

4. Nodo de Acción (Salida): Genera la respuesta por correo o registra los datos en el sistema.

📜 Flujo de Ejemplo 2

Flujo de Respuesta a Peticiones Normativas

Entrada: Petición de información de cliente o consulta técnica vía formulario o API.

PROCESO: Asesoría Legal y Cumplimiento

El flujo toma la consulta recibida, consulta los manuales autorizados de la empresa y genera la respuesta oficial incluyendo obligatoriamente la cita [E1] del documento.

✔ Cero Invención: Si el documento de referencia no contiene la respuesta, el flujo notifica "Sin evidencia suficiente".

Flujo de Triaje de Alertas de Seguridad y Sistemas

🛠️ Guía de Uso

¿Cómo Se Configura y Utiliza Flentio?

1. Elegir Entrada

Define la señal de origen: correo, webhook de otra app o API.

2. Conectar Bloques

Añade filtros de seguridad DLP y reglas con el diseñador visual o Copiloto.

3. Probar en Preproducción

Valida el flujo con firma digital en el entorno seguro de pruebas.

4. Publicar y Ejecutar

Activa el flujo para procesar peticiones en vivo 24/7.

🔄 Ciclo de Vida

Entornos de Trabajo para Cambios Seguros

Los flujos en Producción están congelados para impedir modificaciones accidentales en vivo.

Control de Versiones Inmutables

1. Desarrollo: Espacio de borrador (v1.0.0-draft) donde puedes hacer cambios con libertad.

2. Preproducción: Congela el flujo en una versión de pruebas (v1.0.0-rc1) firmada con hash SHA-256.

3. Producción Real: Versión congelada activa. Cualquier cambio requiere clonar un nuevo borrador a Desarrollo.

🔒 Custodia y Auditoría

Auditoría Inalterable de Ejecuciones

Cada ejecución de un flujo queda registrada en un historial inmutable antialteración.

Trazabilidad Completa

La plataforma calcula la firma digital SHA-256 de cada documento y evento. Si se detecta cualquier intento de manipulación, el sistema inabilita el archivo y alerta a los administradores.
